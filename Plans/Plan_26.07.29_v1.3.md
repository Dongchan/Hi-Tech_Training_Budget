# v1.3 중복성 검토 계획 (Plan_26.07.29_v1.3)

작성: 2026-07-29 | 전제: v1.2까지 완료. 대시보드의 중복·유사 의심 그룹은 "검토 후보" 상태

## 목적

인재양성 사업이 걸린 유사도 그룹 13개(구성 사업 86개)의 **실질 중복 여부를 내용 기반으로 판정**하여, "의심 후보" 상태를 "판정 결과"로 끌어올린다.

## 방법

| 단계 | 내용 |
|---|---|
| 1 | 그룹별 작업 파일 생성 (구성 사업의 부처·사업명·2026 예산 보정값·사업목적 요약·원문 경로) — 완료 |
| 2 | 그룹당 에이전트 1명(Opus 5 medium × 13)이 구성 사업의 PDF 원문(사업목적·내용·내역)을 비교 판정. 8개 이하 그룹은 원문 정독, 대형 그룹(19·31개)은 목적 요약 대조 후 의심 쌍만 원문 확인 |
| 3 | 판정 체계: **중복 소지(duplicate)** 동일 목적·대상의 분산 편성 / **보완·분담(complementary)** 역할·대상·단계가 구분됨 / **무관(unrelated)** 명칭 유사일 뿐 / **혼재(mixed)** 그룹 내 일부 쌍만 중복 소지. 심각도(상·중·하)와 겹침 지점, 사업별 역할 요약 포함 |
| 4 | 리더 종합·판정 확정 → `analysis\duplication_review_v13.json`, `Reports\중복성_검토_v1.3_26.07.29.md`, 대시보드 그룹 카드에 판정 칩·근거 반영 |

## 검증 기준

1. 13개 그룹 전부 판정 완료 (미판정 0)
2. 판정마다 겹침 지점 또는 구분 근거가 원문 기반으로 기재
3. 대시보드 카드의 "검토 후보" 문구를 판정 결과 표시로 대체
