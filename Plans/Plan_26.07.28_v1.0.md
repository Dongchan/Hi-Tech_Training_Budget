- **범위 결정(사용자 확정)**: ① 정합성 검증은 **533건 전수**, ② 산출물은 **검증 보고서 + 인재양성 예산 현황 보고서**까지.

## 실행 단계

### Phase 0 — 환경 준비
1. `git clone https://github.com/hollobit/KAIB2026.git` → 프로젝트 폴더 내 `KAIB2026\`
2. `Plans\` 폴더 생성, 본 계획을 `Plans\Plan_26.07.28_v1.0.md`로 저장
3. `Work_history.md` 생성 — **최신 작업이 최상단**, 각 항목에 시각·소요시간 기록. 날짜/시간은 반드시 Python(`datetime.now()`)으로 확인해 기재 (지시사항)
4. PDF 실제 페이지 수 측정(PyMuPDF)으로 "5천 페이지" 검증

### Phase 1 — data/js 구조 분석
- data 7개 JSON 로드, 실측 스키마 vs `Data-format.md` 문서 스키마 대조 (필드 누락·타입 불일치)
- js 8개 모듈 분석: `ai_domains`/`ai_tech` 분류 로직의 소재 확인 (데이터 생성 시 고정 vs JS 렌더링 시 계산) — 특히 `policy-cluster.js`, `budget-insight.js`
- `ISSUE.md` 문제 목록을 정형 체크리스트(`analysis/checklist.md`)로 변환

### Phase 2 — 파이썬 전수 자동 검사 (533건, 저비용 선행 게이트)
`scripts\` 아래 UTF-8 파이썬 스크립트 작성·실행:
- **A. 페이지 매핑 검증**: toc_mapping의 각 페이지 범위에서 사업명·부처명 텍스트 실재 확인 → 어긋나면 Phase 3 입력이 오염되므로 **선행 게이트**
- **B. 계층/코드 검증**: 사업코드 형식(NNNN-NNN), 프로그램→단위→세부 계층 일관성, 부처 41개 목록, id/name 중복
- **C. 산술 검증**: 내역사업(sub_projects) 합계 vs 모사업 예산, 증감액·증감률 역산 일치
- **D. raw↔db 교차 검증**: 533건 공통 필드 값 일치 여부
- **E. 대조용 텍스트 추출**: 사업별 PDF 페이지 텍스트를 `extracted\{id}_{사업명}.txt`(UTF-8)로 저장 → Phase 3 에이전트 입력 (에이전트가 116MB PDF를 직접 읽지 않게 함)

### Phase 3 — 에이전트 팀 전수 대조 (533건)
- **팀 구성(지시사항)**: 팀 리더 = Fable 5 xhigh(본 세션 — 배치 설계·결과 종합·최종 판정), 팀원 = **Opus 5 medium** (`model: 'opus'`, `effort: 'medium'`)
- Workflow 도구로 fan-out: 533건 ÷ 배치 약 40건 = **검증 에이전트 ~14개**
- 각 에이전트는 배치 내 사업별로 구조화 JSON(schema 강제) 반환:
  1. 추출 텍스트 ↔ budget_db.json **수치 대조** (예산 7필드, 사업기간, 총사업비)
  2. **분류 타당성 판정**: ai_domains/ai_tech가 사업목적·내용과 부합하는가, 비AI 사업 혼입 여부, 특히 **'교육/인재' 도메인의 오분류·누락**
- 리더가 종합: 문제 판정 건은 **별도 에이전트로 2차 교차검증** 후 확정 → `analysis\verification_results.json`

### Phase 4 — 인재양성 예산 현황 추출
- 이중 필터: '교육/인재' 도메인 ∪ 키워드(인재양성·인력양성·교육·대학·훈련·장학 등) → 후보 사업 추출
- Phase 3 결과로 오분류 제거·누락 보완한 **확정 인재양성 사업 목록**
- 부처별·사업별 2024결산→2025→2026 예산 정리, 중복 의심 그룹 표시(예: AI·SW중심대학 3개 부처 1,552억)
- 메일 5번 관점 매핑: 각 사업·데이터를 조사데이터/행정데이터/가공데이터로 구분

### Phase 5 — 보고서 작성
- `Reports\분류체계_정합성_검증보고서_26.07.28.md` — 검증 항목별 결과, 발견 문제 목록(심각도 구분), ISSUE.md 자체 보고와의 비교
- `Reports\첨단분야_인재양성_예산현황_26.07.28.md` — 확정 사업 목록, 부처별·연도별 예산, 중복·데이터 출처 구분
- 매 Phase 종료 시 `Work_history.md` 갱신 (최상단 삽입, Python으로 시각 확인)

1. Phase 2 스크립트 결과에서 무작위 10건을 PDF 원본 페이지로 수동 spot-check
2. Phase 3에서 문제 판정 건 **전수** 2차 교차검증 + 정상 판정 표본 5% 재검
